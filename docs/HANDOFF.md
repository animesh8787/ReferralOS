# Handoff
**Built:** ReferralOS, a multi-user referral/resume/outreach platform (FastAPI + SQLAlchemy + Alembic, Next.js, DB task queue, SQLite or PostgreSQL; 35 tables, 126 paths). Nothing is sent without per-message approval through one preflight gate; unknown stays "unknown"; resumes only contain facts from the profile. Details: DECISIONS.md, PROGRESS.md.

**Run:** copy .env.example to .env; `cd backend && uv sync && uv run alembic upgrade head`; `uv run uvicorn app.main:app --port 8000`; worker: `uv run python -m app.worker`; `cd frontend && npm install && npm run dev`. Offline: ADAPTER_MODE=mock. Tests: `uv run pytest` (TEST_DATABASE_URL for Postgres).

**Verified:** see TEST_REPORT.md and PERFORMANCE.md. **Real:** GitHub public API and 5 ATS board APIs (read-only, once). **Mock only:** Gmail send/OAuth, LLM. **Not verified:** docker compose, real resumes.

**Needs configuration:** Google OAuth client, optional LLM key, APP_KEK, HTTPS, a mail provider, optional GitHub token (PUT /api/settings/github-token, no UI field).

**Limits:** SQLite single-user; no OCR; per-process rate limits; DNS rebinding not pinned (SECURITY.md); English only; no SMTP or open tracking; frontend/AGENTS.md is generated by next dev.
